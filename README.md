# AzurePlay Blog Admin Panel

Локальный редактор JSON-файлов. Позволяет работать с данными в виде таблиц с drag-and-drop, редактировать вложенные массивы и переключаться на сырой JSON.

## Возможности

- **Кросс-браузерная работа** через локальный Express-сервер (Chrome, Firefox, Safari, Edge)
- **Табличный редактор** для массивов объектов:
  - Drag & Drop строк
  - Редактирование ячеек двойным кликом (поддержка `\n`)
  - Кнопка удаления строки
  - **Дублирование строк** — копия создаётся сразу под текущей
  - **Пагинация по 10 записей**
  - **Колонка «Порядок»** — изменение позиции записи без сохранения в JSON
  - Автоматический пересчёт числовых `id` после перемещения/удаления (строковые `id` не затрагиваются)
- **Поддержка вложенных массивов** объектов — открываются в модальном окне с табличным редактором или JSON
- **Режим сырого JSON** с Monaco Editor, изменяемой высотой и ручкой ресайза
- **Создание новых JSON-файлов** с выбором начального содержимого (пустой массив, объект или копия текущего)
- **Удаление файлов** с модальным подтверждением
- **Тёмная тема** Bootstrap 5 с переключением
- **Экспорт** всех файлов в ZIP для загрузки на сайт
- **Алфавитная сортировка** файлов в боковой панели
- Сохранение по **Ctrl+S** в любом режиме

## Технологии

- React 18 (Create React App)
- React Bootstrap
- @monaco-editor/react
- @hello-pangea/dnd (Drag & Drop)
- JSZip + file-saver (экспорт)
- Express (локальный API для файловых операций)

## Установка и запуск

```bash
git clone https://github.com/AzureLinker/azureplay-blog-adminpanel.git
cd azureplay-blog-adminpanel
npm install
```

### 1. Подготовка данных
  Создай папку `data/` в корне проекта и скопируй в неё свои JSON-файлы. Express-сервер работает с этой папкой.

### 2. Запуск (редактор + сервер одновременно)
```bash
npm run dev
```
Или раздельно:
```bash
npm run server    # Express на http://localhost:3001
npm start         # React на http://localhost:3000
```
Открой http://localhost:3000 в любом браузере.

### 3. Работа с файлами
- Редактор автоматически загружает все `.json`-файлы из папки `data/`.
- При сохранении изменения записываются обратно в файлы на диске.
- Чтобы выгрузить данные, нажми **"Экспорт ZIP"** и загрузи архив на сайт, либо скопируй файлы из папки `data/` вручную.

## Использование
1. При запуске редактор загружает все JSON-файлы из папки `data/`. В левой панели появится список файлов. Выбери нужный.

1. Для массивов объектов откроется табличный редактор. Доступны действия:
    - Добавление строки (кнопка "+ Добавить строку")
    - Удаление строки (кнопка ✕)
    - Дублирование строки (кнопка ⧉) - копия создаётся сразу под текущей
    - Перетаскивание строк за ручку ⠿
    - Изменение порядка - двойной клик по номеру в колонке "Порядок", ввод новой позиции

1. Вложенные массивы объектов (например, links) отображаются с кнопкой ✎. При клике открывается модальное окно с таким же табличным редактором.

1. Нажми «Таблица» / «JSON» для переключения режима. В JSON-режиме доступен Monaco Editor с изменяемой высотой.

1. Внесите изменения и нажмите «Сохранить файл» или используйте Ctrl+S – данные запишутся обратно на диск.

1. Чтобы выгрузить все файлы на Neocities, нажми «Экспорт ZIP».

1. Для создания нового файла нажмите «+ Новый файл» (рядом с кнопкой открытия папки). Укажите имя и начальное содержимое (пустой массив, объект или копию текущего файла).

1. Для удаления файла нажмите 🗑 рядом с его именем в списке – потребуется подтверждение.

## Примечания
- Папка `data/` — рабочая директория. Все изменения сохраняются напрямую в файлы внутри неё.
- Express-сервер должен быть запущен параллельно с React-приложением. Скрипт `npm run dev` делает это автоматически.
- При перетаскивании и удалении элементов числовое поле `id` автоматически пересчитывается (1-based). Строковые идентификаторы остаются без изменений.
- Колонка "Порядок" не сохраняется в JSON - используется только для локального перемещения записей.
- В режиме сырого JSON редактор можно растягивать за нижний край.
- Для выгрузки на Neocities используй экспорт ZIP или копируй файлы из `data/` напрямую.
